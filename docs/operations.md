# التشغيل والصيانة

## الخدمات

خادم Next.js وقاعدة PostgreSQL عمليتان يجب تشغيلهما مجددًا. توجد تبعيات JavaScript في `node_modules`، والإعدادات الخاصة في ملفات `.env*` المتجاهلة، وبيانات PostgreSQL في وحدة Docker المسماة `praxis_praxis-data`.

```sh
docker compose --env-file .env.db up -d --wait
npm run db:migrate
npm run dev
```

فحص `GET /api/health` يختبر اتصال قاعدة البيانات. فحص رحلة الطالب الفعلي هو `npm run test:e2e` مع خادم محلي في وضع development؛ يرفض التشغيل على عنوان خارجي أو وضع pilot.

```sh
npm run build
npm run start
```

قاعدة البيانات المحلية تستمع على loopback فقط، بكلمة مرور مولدة. في الاستضافة اضبط `DATABASE_URL` واتبع إعدادات TLS للمزود؛ لا تعطّل تحقق الشهادات. لا تستخدم بيانات التطوير أو رمز المشرف المحلي في نشر عام.

## حفظ البيانات واستعادة البيئة

لا تفترض أن عمليات الخادم أو وحدات Docker تبقى في بيئة سحابية جديدة. احتفظ بنسخة احتياطية داخل مسار تحفظه المنصة أو مخزن معتمد قبل إتلاف بيئة تحتوي بيانات فعلية.

```sh
mkdir -p .data
docker compose --env-file .env.db exec -T postgres pg_dump -U praxis -d praxis --no-owner > .data/praxis.sql
```

لا تستعد فوق بيانات موجودة دون مراجعة. لقاعدة جديدة فارغة فقط، يمكن تمرير النسخة إلى `psql -U praxis -d praxis` داخل خدمة postgres. نسخة الإعداد الحالية يمكنها إعادة بناء مخطط فارغ، ولا تدّعي استعادة بيانات لم تُنسخ احتياطيًا.

## الأسرار والخدمات الاختيارية

- `PRAXIS_ADMIN_TOKEN`: سر خاص للوصول إلى الإدارة. لا يظهر في الواجهة أو Git.
- `PRAXIS_AI_API_KEY` و`PRAXIS_AI_MODEL`: موصل اختياري إلى `api.openai.com`؛ ليسا مطلوبين للتدريب بالتلميحات المرجعية.
- `PRAXIS_AI_DAILY_REQUEST_LIMIT`: حد أقصى عالمي للاستدعاءات اليومية من التطبيق، افتراضيًا 100. التقييم اليدوي المستقل له حد حالات منفصل ويُحسب في الميزانية.
- `PRAXIS_TELEGRAM_CHANNEL_URL`: رابط قناة مملوكة، اختياري في صفحة انتظار الإطلاق.
- `PRAXIS_PILOT_CODE`: رمز دخول للتجربة الصغيرة؛ لا يحل محل هوية قوية عند التوسع.

أعلام الجاهزية لا تنشئ دليلًا تلقائيًا. لا تضبطها دون العمل الموثق المقابل لها. `PRAXIS_SECURE_COOKIES=true` يتطلب HTTPS فعليًا.

## الحذف الدوري

يمكن للمشارك حذف بياناته من صفحة التقدم. قبل الإطلاق جدوِل الأداة التالية يوميًا وفق سياسة الاحتفاظ المتفق عليها:

```sh
node --env-file=.env.local scripts/prune-data.mjs
```

تحذف المشاركين الأقدم من 90 يومًا وسجلاتهم التابعة، وتنظّف حدود المعدل المنتهية. يجب تطبيق سياسة مماثلة على النسخ الاحتياطية. لا توجد مهمة مجدولة مفعلة في هذه البيئة بعد.

## القيود الحالية

لا توجد مصادقة تيليجرام أو استعادة حساب عبر جهاز آخر، ولا مزود دفع أو Webhook أو نشر عام. النصوص القانونية والمحتوى لم يعتمدا. تقارير النموذج غير منفذة حتى تتوفر إعداداته. هذه المتطلبات لا تمنع التطوير المحلي، لكنها تمنع الادعاء بأن المنتج جاهز للإطلاق.
