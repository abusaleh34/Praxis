# مراجعة المحتوى والتلميحات

كل الأسئلة مسودات أصلية؛ لا تُمنح علامة الاعتماد آليًا. مخطط المهارات هنا مبدئي، ويجب مطابقته مع مرجع قياس الرسمي دون افتراض نسبة الهندسة من القسم الكمي.

المعلم يراجع لكل سؤال: وضوح اللغة، وصحة المعطيات والرسم، والحل، وفرادة الإجابة الصحيحة، ومعقولية المشتتات وتفسير كل خطأ، وترتيب التلميحات وعدم كشف الإجابة مبكرًا، وملاءمة المستوى.

توزيع المهارات متطابق بين القبلي والبعدي، لكن تكافؤ الصعوبة غير مثبت. يحتاج المعلم مراجعة الاختبارين كمجموعتين، ومنع تسريب أسئلتهما إلى التدريب.

الدخول إلى `/admin` ثم «مراجعة المحتوى» يعرض السؤال وحله وتلميحاته. زر الاعتماد يحتاج اسم مراجع وإقرارًا صريحًا. الاعتماد مرتبط ببصمة JSON؛ أي تعديل في السؤال يبطل اعتماده حتى يراجَع مجددًا.

## حزمة جودة التلميحات

`npm run quality:authored` ينشئ `quality-results/authored-review.json`: 150 حالة، ثلاث إجابات خاطئة لكل سؤال من الخمسين، ولكل حالة التلميحات الثلاث. إنه ملف مراجعة لا تقرير نجاح.

عند اختيار نموذج، تشغل حزمة النموذج بالإعدادات المراد إطلاقها، ويُوثّق النموذج وبصمة البنك. يراجع المعلم صحة التصحيح والتلميحات وملاءمتها للخطأ واتساقها مع الرسم. يُقترح احتساب الحالة صحيحة فقط إذا اجتازت التلميحات الثلاث جميع المعايير؛ ثبّت هذا قبل القياس. 143 حالة ناجحة من 150 تتجاوز 95%، و142 لا تبلغها.

لم تُنفّذ مراجعة بشرية أو قياس نموذج بعد. لا تضبط `PRAXIS_HINT_QUALITY_APPROVED=true` قبل تقرير موقع وصالح لإصدار المحتوى والنموذج الحالي. تغيير النموذج أو التعليمات أو البنك يستلزم إعادة التقييم. سجّل التقرير والمراجع والتاريخ، وعالج الأخطاء الجوهرية حتى لو تجاوز المتوسط العتبة.

لا تشغّل `content:generate` بعد مراجعات بشرية دون نسخة احتياطية؛ فهو يعيد إنتاج بنك المسودات وقد يستبدل تعديلات المراجع. عدّل ملف المحتوى مباشرة عند التصحيح، ثم شغّل فحوصه وأعد اعتماد البصمة.
