## التحقق

`npm test` لاختبارات المحتوى والحساب والتحليل؛ `npm run test:e2e:fixes` لحالات المراجعة الجديدة؛ ومجموعات `test:e2e` و`test:e2e:mentor` و`test:e2e:review` و`e2e-learning-journey.mjs` للمسارات القائمة. اختبارات المتصفح تنشئ حسابات مراجعة منفصلة وتحذفها بعد الانتهاء.

المخطط يضيف `solving_ms` و`content_set` إلى الأنشطة دون حذف أو تغيير مفاتيح الإجابات القديمة. `content_set=0` يحتفظ بالبنك الأصلي؛ القراءة تعرض أكبر الزمنين القديم والجديد حتى دون ترحيل قيم الوقت السابقة.
